# 해온한의원 홈페이지

현재 다중 페이지 구성: 메인, 한의원 소개/기록/사회공헌, 의료진 전체 및 4인 상세, 7개 진료 분야 및 한방내과 세부 안내 14개 (호흡기 10개·소화기 4개), 소아과 17개, 부인과 21개, 진료시간/위치/공간, 전체 페이지.

## 미리보기

이 폴더에서 `python3 -m http.server 8873 --bind 127.0.0.1` 실행 후 http://127.0.0.1:8873/ 접속. HTML을 직접 열어도 메뉴와 본문을 사용할 수 있습니다.

## 공통 수정과 생성

- `scripts/build_site.py`: 공통 메뉴, 진료 분야·의료진 구성, 각 페이지 구조. 외부 패키지 불필요.
- `assets/styles/shared/home.css`: 첫 메인 화면에서 이어온 기본 디자인.
- `assets/styles/shared/site.css`: 다중 페이지 공통 메뉴, 의료진, 본문, 목차, 갤러리 등.
- `assets/scripts/shared/home.js`: 전체 메뉴 닫기, Escape 키 처리. 기본 이동은 JavaScript 없이도 작동.
- `content/`: 원문 자료, 기존 로컬 HTML 백업, 이관 목록.

공통 내용을 수정한 다음 `python3 scripts/build_site.py`로 73개 정적 HTML을 생성합니다. 생성기는 해당 HTML을 덮어쓰므로 직접 HTML에서 수정한 내용을 유지하려면 생성기/입력 자료에도 반영해야 합니다. 첫 메인의 본문은 `content/legacy/index.html`을 바탕으로 구성됩니다. 이후 개발 시 템플릿 분리가 가능합니다.

`python3 scripts/check_site.py`로 로컬 링크, 이미지, 내부 앵커, 공통 메뉴, 의료진 원문 보존을 확인합니다.

[MIGRATION.md](MIGRATION.md)에 기존 메뉴 73개의 새 페이지 연결 및 이관 상태를 기록했습니다. 한방내과는 주요 세부 안내 10개의 본문·사진을 로컬 페이지로 이관했습니다. 소아과·부인과도 38개 상세 페이지로 이관했습니다. 아직 이관하지 않은 분야와 연관 게시물은 기존 홈페이지로 연결됩니다. 전체 사이트 이관 완료를 의미하지 않습니다.

- `scripts/check_site.py`에서 원문·자료 연결 보존, 실제 사진 중복, 요약·모바일 메뉴도 확인.

브라우저 회귀 검사: Playwright와 Chrome이 설치된 환경에서 `node scripts/check_internal.cjs`. 11개 화면의 1440/390/320px 배치, 이미지 로딩, 이동 메뉴, 모달, 키보드 초점, 스크롤 복구와 JavaScript 비활성 상태를 검사합니다. 별도 경로의 Playwright를 쓸 때는 `NODE_PATH`로 해당 `node_modules`를 지정합니다.

## 첫 화면 히어로 롤링

`scripts/home_hero.py`에서 사진 3장과 문구·연결 페이지를 관리합니다. 한의원 진료실 → 초음파·검사가 있는 스포츠진료실 → 4인 의료진 순서입니다. 이야기를 듣는 진료, 객관적인 검사, 18년째·20만 건 이상의 진료 경험 위에 환자의 이야기를 더하는 흐름으로 이어집니다. 진료 기간과 건수는 사용자 제공 문구를 반영했습니다. 의료진 사진은 히어로에 한 번만 표시하고 아래 본문의 중복 사진은 제거했습니다.

`assets/styles/home/home-hero.css`, `assets/scripts/home/home-hero.js`는 첫 페이지에만 적용됩니다. 6초 간격 자동 전환, 직접 선택·이전·다음, 방향키·모바일 스와이프를 지원합니다. 수동 선택 후에도 자동 전환을 이어갑니다. 본문 링크에 키보드 초점이 있는 동안만 전환을 기다리고, 초점이 벗어나면 재개합니다. 동작 줄이기 설정에서는 전환 애니메이션만 생략합니다. 재생·정지 버튼은 표시하지 않습니다. JavaScript가 꺼져 있어도 첫 장과 진료·검사 공간 링크를 사용할 수 있습니다.

### 2026-09 공통 디자인 기준
외부 스타일 가이드 적용을 철회하고 홈 사진 히어로의 차콜 톤을 기준으로 정돈했습니다. `assets/styles/shared/unified.css`가 화이트·회색 배경, 차콜 버튼, 5px 모서리와 공통 헤더 크기를 관리합니다. 진료과별 CSS에서도 같은 중립색 토큰을 사용합니다.

- 통증재활: `pain1.html` → `/pain1` (기존 통증재활 본문 유지)

메뉴·상세 페이지·사이트맵은 새 HTML 파일을 연결합니다. `scripts/page_routes.py`에서 진료과별 파일명을 관리합니다. 이전 파일명은 새 페이지로 이동하는 호환용 HTML만 남기며, 생성기를 다시 실행해도 유지됩니다.

확장자 없는 주소는 웹 서버 설정이 필요합니다. Apache에서는 루트의 `.htaccess`도 함께 배포하고 `mod_rewrite` 및 `AllowOverride FileInfo`를 허용해야 합니다. 네 주소를 해당 HTML로 내부 연결하고, 이전 파일명과 새 `.html` 주소는 짧은 주소로 301 이동합니다. 다른 호스팅은 이에 대응하는 rewrite/redirect 설정이 필요합니다. 기본 `python3 -m http.server` 미리보기는 `.htaccess`를 적용하지 않으므로 `.html` 주소로 확인합니다.

## 사진·스타일·스크립트 모듈

사진은 `assets/images/` 아래에서 로고·의료진·공간·위치·진료 자료별로, CSS와 JavaScript는 `assets/styles/`, `assets/scripts/` 아래에서 공통·홈·진료과·진료 안내별로 관리합니다. 자세한 구조와 사진 교체 방법은 [자산 관리 안내](assets/README.md)를 참고하세요.

`python3 scripts/build_site.py`를 실행하면 `content/asset-catalog.json`에 전체 파일의 사용 페이지·원본 출처·해시·중복 여부도 자동 기록합니다. 추가 확인은 `python3 scripts/check_assets.py`로 실행합니다. 원문 백업과 게시 제외 이미지는 보존합니다.
